# Struve LLM 0.8.2-alpha.1 для Windows x64

Struve LLM изначально задумывался как помощник в разработке астрономического проекта «Струве-Астро». В одном чате можно разбирать исходный код с локальной языковой моделью, задавать вопросы по документам и сохранять принятые решения в памяти проекта. Из нового диалога можно вернуться к источнику такого решения. Координатор может выполнять те же действия через CLI.

При необходимости к работе можно подключить генеративные модели. Например, чтобы подготовить ролик о проекте, можно обсудить сценарий с языковой моделью, приложить референсные кадры и передать задачу видеомодели. Готовый ролик появится в том же чате. Там же можно создать иллюстрацию по описанию или попросить отредактировать изображение.

Это первая альфа с отдельным установщиком для проверки на других ПК. В первом окне выберите **English** или **Русский**. Мастер и первое окно приложения используют этот язык. Установщик работает в профиле пользователя, добавляет ярлык и регистрирует приложение для удаления через настройки Windows. Альфа включает CPU-движок llama.cpp для подключения своего GGUF. В окне и CLI отображается базовая версия 0.8.2.

Интерфейс доступен на русском и английском. В разделах «Модели» и «Ресурсы» можно сопоставить модели с устройствами, задать бюджет и выяснить, почему задача ожидает. В расширениях доступны подключения MCP и инструменты для документов. Чат поддерживает профили генерации и правки изображений и видео при наличии соответствующих движков и весов.

Для пробного запуска скачайте Windows x64 Setup. При наличии WebView2 базовая установка работает без подключения к сети. Свою GGUF-модель можно хранить на любом диске, доступном текущей учётной записи. Тяжёлые модели, CUDA-движки и ComfyUI настраиваются отдельно.

Особенно пригодятся отчёты с других конфигураций: первый запуск, точность инвентаризации устройств, ответ выбранной модели и поведение после выхода из трея. [Порядок проверки](TEST_SECOND_PC_RU.md) · [Сборка и участие](BUILD.md)
