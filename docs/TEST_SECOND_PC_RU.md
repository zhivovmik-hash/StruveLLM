# Проверка Struve LLM на втором ПК

Возьмите установщик **Struve-LLM-0.8.2-alpha.1-windows-x64-setup.exe**. Для проверки ответа модели возьмите также свой небольшой GGUF диалоговой модели с поддержкой llama.cpp, подходящий по объёму оперативной памяти. Для проверки окна, ресурсов и встроенных MCP файл весов не требуется.

Для воспроизводимой проверки на CPU можно взять **Qwen2.5 0.5B Instruct Q4_K_M**. Размер файла 491 400 032 байта. Его SHA-256 — `74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db`. Скопируйте GGUF рядом с установщиком на флешку или скачайте заранее, а в мастере укажите путь к нему. [Файл в официальном репозитории Qwen](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/9217f5db79a29953eb74d5343926648285ec7e67/qwen2.5-0.5b-instruct-q4_k_m.gguf) · [Описание и лицензия модели](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/tree/9217f5db79a29953eb74d5343926648285ec7e67)

## Установить

Первый диалог установщика подписан **Select a language / Выберите язык**. Если выбрать **English**, последующие шаги, первое окно Struve LLM и меню в трее будут на английском. При повторной установке уже сохранённый язык приложения имеет приоритет. Для тихой установки доступны `/S /LANG=en` и `/S /LANG=ru`.

1. На ПК с Windows 10 или 11 x64 оставьте около 2 ГиБ свободного места для приложения и временных файлов. Файлы моделей и результаты генерации потребуют дополнительного места. Сверьте вывод `Get-FileHash .\Struve-LLM-0.8.2-alpha.1-windows-x64-setup.exe -Algorithm SHA256` с файлом SHA256SUMS.txt выпуска.
2. Запустите установщик от обычной учётной записи. Выберите пустую папку или оставьте предложенную. Установка по умолчанию — `%LOCALAPPDATA%\Programs\Struve LLM Alpha`. Данные пользователя создаются рядом с папкой `app`, поэтому каталог должен быть доступен для записи. Альфа-установщик без цифровой подписи издателя.
3. Окно использует Microsoft Edge WebView2 Runtime. Если компонента ещё нет, установщик вызовет подписанный загрузчик Microsoft, которому требуется интернет. Для автономного ПК можно заранее установить Evergreen Standalone Installer x64. [Загрузка Microsoft WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
4. Запустите **Struve LLM Alpha** с рабочего стола. Язык интерфейса меняется в настройках. Если при запуске стороннего движка Windows сообщает об отсутствующей библиотеке MSVC, установите официальный x64 Redistributable и повторите. [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)

## Что проверить за первый сеанс

| Действие | Ожидаемый результат |
| --- | --- |
| Открыть «Ресурсы» | Названия CPU и доступных GPU соответствуют этому ПК. Без NVIDIA доступна работа через CPU. |
| Открыть «Модели» | Можно подключить первую модель. Чаты, профили моделей и вложения автора отсутствуют. |
| В мастере выбрать «Файл GGUF на компьютере», свой GGUF и «CPU + RAM» | Автоматически найден комплектный `runtimes\llama.cpp\llama-server.exe`. Мастер предлагает профиль с учётом свободной памяти. Подтвердите его. |
| Отправить «Сколько будет 2 + 2? Ответь числом» | В диалоге появляется ответ, задача заканчивается, расход памяти можно посмотреть в разделе ресурсов. Корректность текста зависит от модели. |
| Прикрепить `examples\AgentPilot\training-log.md` из папки установки | Правая панель открывает учебный Markdown. Включённое подключение документов позволяет читать файл из проекта с соответствующими разрешениями. |
| Скрыть окно крестиком, открыть через трей, затем выбрать «Выход» | Открывается тот же диалог. После выхода управляемые приложением процессы завершаются. |

Для CUDA выберите совместимый с картой и драйвером `llama-server.exe` в мастере и назначьте GPU. Для первого теста медиа укажите отдельно движок генерации, веса и профиль устройства. Внешние серверы, которые вы запустили самостоятельно, останавливаются отдельно.

## Если что-то не получилось

Из корня установки выполните `.\bin\struve-llm.cmd --json diagnostics`. Перед передачей отчёта просмотрите его содержимое. Приложите версию Windows, имя GPU, тип модели и движка, шаг, на котором возникла проблема, точный текст ошибки и ожидаемый результат. Вкладка «Журнал» помогает отличить нехватку ресурсов от ошибки движка. Для удаления выберите **Struve LLM Alpha** в установленных приложениях Windows после выхода из трея. Чаты, вложения и добавленные пользователем файлы остаются в каталоге установки.
