# Struve LLM

Struve LLM изначально задумывался как помощник в разработке астрономического проекта «Струве-Астро». Это настольное приложение для Windows, в котором можно работать с локальной языковой моделью, исходным кодом и документами в одном чате. Например, можно приложить фрагмент кода обработки снимка и попросить модель объяснить его или задать вопрос по таблице из отчёта.

Когда для проекта нужна иллюстрация или видеоролик, можно подключить подходящую генеративную модель. Описание задачи и референсы передаются в том же диалоге, и готовое изображение или видео появляется в переписке. Из чата также можно поручить модели поиск или попросить отредактировать изображение.

У каждого проекта свои диалоги, общая память и разрешённые инструменты. Тем же диспетчером можно управлять из терминала.

## Первый запуск

Скачайте установщик Windows x64 со [страницы альфа-версии](https://github.com/zhivovmik-hash/StruveLLM/releases/tag/v0.8.2-alpha.1). Там же лежит `SHA256SUMS.txt` для проверки загрузки.

1. Запустите установщик Windows x64. В первом окне выберите **Русский** или **English**, затем папку, доступную для записи. На выбранном языке откроются мастер и само приложение. Установщик создаёт ярлыки на рабочем столе и в меню «Пуск».
2. Откройте **Struve LLM Alpha → Ресурсы**. Сверьте обнаруженные CPU, память, видеокарты и диски с конфигурацией компьютера.
3. В разделе **Модели → Подключить первую модель** выберите локальный GGUF и **CPU + RAM**. CPU-движок llama.cpp входит в установщик. Для ответа в чате нужен файл весов совместимой диалоговой модели. Альтернативный способ — подключить уже работающий на компьютере Ollama или OpenAI-совместимый сервер.
4. Создайте чат и отправьте короткий вопрос. Крестик скрывает окно в трей. Команда **Выход** в меню значка завершает приложение и останавливает управляемые им модели.

## Возможности альфы

| В окне | Для чего |
| --- | --- |
| Чат и память проекта | Прикреплять материалы, задавать длину контекста, сохранять решения и переходить к их источникам из других диалогов проекта. |
| Правая панель | Читать Markdown с таблицами и диаграммами, просматривать исходный код, документы, изображения и страницы во вкладках. |
| Ресурсы | Выбирать CPU и GPU, задавать резерв памяти, смотреть фактическое потребление и причину ожидания задачи. Возможность параллельного запуска зависит от свободных ресурсов и движка. |
| Генераторы | Выбирать профили SD, FLUX и H3, задавать ресурсы для каждого, передавать промпты и референсы и открывать результат в чате. Для GPU-генерации требуются отдельно установленные совместимые движки и веса. |
| Расширения | Подключать MCP, регистрировать команды CLI и IDE, выбирать разрешённые инструменты. Встроенные подключения поддерживают документы, таблицы и поиск в интернете. |
| CLI | Запрашивать инвентарь ПК, отправлять сообщения, отслеживать задачи и читать память проекта через JSON. |

Веса генеративных моделей поставляются отдельно. В установщик входят Node.js, FFmpeg, CPU-среда для редактирования с масками SlimSAM и CPU-движок llama.cpp. Ускорение на NVIDIA требует отдельной CUDA-сборки движка и совместимого драйвера. Поддержка конкретного профиля изображения или видео зависит от семейства весов, движка и доступной памяти. Научное обучение моделей Struve-Astro пока не подключено.

## Команды для проверки

В PowerShell откройте папку установки и выполните:

```powershell
.\bin\struve-llm.cmd --json doctor
.\bin\struve-llm.cmd --json resources list
.\bin\struve-llm.cmd --json model list
.\bin\struve-llm.cmd --json mcp probe documents
```

## Присоединиться к разработке

Мы приглашаем пользователей и разработчиков делать Struve LLM вместе. Можно участвовать на русском или английском.

- **Есть идея?** Расскажите, какую задачу вы хотели решить и как она должна выглядеть в приложении. [Предложить функцию](https://github.com/zhivovmik-hash/StruveLLM/issues/new?template=feature.yml)
- **Попробовали на своём ПК?** Особенно интересны первый запуск и поведение при нехватке памяти. Если что-то пошло не так, укажите версию Windows, оборудование и шаги. [Сообщить об ошибке](https://github.com/zhivovmik-hash/StruveLLM/issues/new?template=bug.yml)
- **Хотите прислать изменение?** Выберите задачу или предложите свою. Создайте форк, внесите правку в отдельной ветке и откройте pull request в `main`. Приветствуются код, переводы, документация и примеры. [Открытые задачи](https://github.com/zhivovmik-hash/StruveLLM/issues) · [Как собрать проект](docs/BUILD.md)
